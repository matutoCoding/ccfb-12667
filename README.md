# 钣金折弯工艺系统（浏览器本地版）

纯 TypeScript + WebGL2 的钣金折弯工艺规划系统。图纸、工艺单、设置全部存在浏览器本地
IndexedDB，**运行期不请求任何外部接口**，可离线使用。适合车间在折弯前核对每一刀的吨位、
模具匹配、法兰边、闭合高度与偏载。

## 启动

```bash
npm install
npm run dev        # 开发，默认 http://localhost:5173（端口被占会顺延/可改 vite.config.ts）
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 预览生产构建
```

## 验证脚本

```bash
node scripts/verify-math.mjs       # BA/OSS/BD/吨位 与手工公式逐项核对
node scripts/integration-test.mjs  # 36 项库级集成测试（校验链、网格、折叠、排序、拦截）
```

## 工程计算模型（全部在 `src/lib/bendMath.ts`）

- K 因子：按材料表中 R/T 比值**线性插值**
- 折弯余量 `BA = π/180 · θ · (R + K·T)`
- 外侧回弹距 `OSS = (R+T) · tan(θ/2)`
- 折弯扣除 `BD = 2·OSS − BA`
- 空弯吨位 `P(kN) = 1.42 · T² · L(m) · Rm / V · 角度系数`，结果除以 9.80665 得吨
- V 槽推荐：按材料倍数（SPCC 6~10T、SUS304 7~12T）× 料厚
- 最小法兰边、闭合高度、滑块压深、左右偏载逐刀校验，超差列出具体数值
- 自动排序：先短后长、先内后外；`orderLocked` 的刀次不会被覆盖

精度说明：公式本身是双精度解析计算，BA/BD 与手工同公式结果误差在 0.0001mm 量级；
实际工艺误差主要来自 K 因子取值，可在设置页按厂内经验表维护，并在编辑页「展开计算校核」
填入手工展开长度做 0.1mm 允差判定。

## 目录结构

```
src/
  types.ts            数据契约
  lib/
    geometry.ts       2D 几何：吸附、环构建、自交、三角化
    bendMath.ts       折弯公式、吨位、可行性、仿真、自动排序
    mesh.ts           面切分、三角网格、逐刀折叠 3D 变换
    glRenderer.ts     WebGL2 渲染器与轨道相机
    sketchCanvas.ts   2D 手绘编辑器
    dimensions.ts     标注联动
    db.ts / store.ts  IndexedDB 与全局状态（切页不丢数据）
    defaults.ts       机床/模具/材料默认库
    samples.ts        三个自带示例零件
    export.ts         程序文件、JSON、自研 PDF 写入器
  pages/              五个页面
```

## 数据与隐私

- 数据库：IndexedDB `bend-system-db`，三个 object store（parts/settings/meta）
- 删除零件先进回收站，按设置天数（默认 7）到期自动清除，也可手动彻底删除
- 所有导出（JSON 图纸、TXT 折弯程序、PDF 工艺单）均在本机生成，无网络上传
